# backend-awabank
# 🏦 AwaBank Backend API

AwaBank is a backend system for a simple banking application that handles user accounts, authentication, and financial transactions.

This project focuses on building secure, scalable backend services using Node.js and SQL databases.

---

## ⚙️ Tech Stack

- Node.js
- Express.js
- PostgreSQL / MySQL (update based on yours)
- JWT Authentication
- Bcrypt (password hashing)

---

## ✨ Features

- User registration and login
- Secure authentication using JWT
- Account creation
- Deposit and withdrawal operations
- Money transfer between users
- Transaction history tracking

### 1. Clone the repository
```bash

2. Install dependencies
npm install
3. Setup environment variables

Create a .env file:

DB_HOST=localhost
DB_USER=your_user
DB_PASSWORD=your_password
JWT_SECRET=your_secret
4. Run the server
node app.js
